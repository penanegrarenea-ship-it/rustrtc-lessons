优先级

// 单个候选（priority_for，mod.rs:4856）
priority = (type_pref << 24) | (local_pref << 8) | (256 - component)
// UDP 的 local_pref = 65535；host + component 1 = 2130706431

// 候选对（IceCandidatePair::priority，mod.rs:5022）
// G = controlling 端候选优先级，D = controlled 端
pair_priority = 2^32 * min(G, D) + 2 * max(G, D) + (G > D ? 1 : 0)

RFC 8445 §5.1.2.1、§6.1.2.3。

检查流程时序

应用交换 SDP（栈外）
  offer 带 a=ice-ufrag / a=ice-pwd / a=candidate
  收集未完成时还可带 a=ice-options:trickle，后续 add_ice_candidate
  收集完成后改为 a=end-of-candidates（vanilla）

各端采集本地候选
  start_gathering → gather_host_candidates
  若配了 ice_servers：probe_stun（srflx）、probe_turn（relay）

角色
  发 offer 的一方：Controlling（create_offer 里 set_role）
  答 answer 的一方：Controlled（对端是 ICE-lite 时除外）

配成 IceCandidatePair，两边都发 STUN Binding
  USERNAME = 远端ufrag:本地ufrag
  MESSAGE-INTEGRITY 用远端 pwd
  controlling 带 ICE-CONTROLLING；controlled 带 ICE-CONTROLLED

有效列表
  检查成功 → ICE successful pair
  controlled 可先占一条临时路，然后等 USE-CANDIDATE

提名（controlling，nomination_grace 之后）
  nominate_best_pair：再发一条带 USE-CANDIDATE 的 Binding
  controlled 跟随；必要时切换已选路径
  commit_selected_pair 发布选中的那一对

之后才是 DTLS / SRTP / SCTP，不在本表。

RFC 8445 §6.1.4、§7、§8。

配置备忘

  • webrtc() 默认 connectivity = Ice、ice_servers = []（src/config.rs:967、999）。要 srflx / relay，自己填服务器。
  • ice_include_loopback_candidates 默认 false（:793）。只有 127.0.0.1 的机器，打开它或设 bind_ips。
  • Trickle：收集未完成时 SDP 带 a=ice-options:trickle，用 add_ice_candidate 继续喂；收集完成则写 a=end-of-candidates，不再声明 trickle。
